# Grace

Grace — персональная система финансового здоровья. Она хранит достоверную
финансовую модель пользователя, выполняет расчёты детерминированно и в будущем
предоставляет ИИ ограниченные инструменты поверх этой модели.

## Первый вертикальный срез

Текущая версия реализует путь Account → Transaction → Category:

- PostgreSQL хранит счета, категории и семантически типизированные операции;
- Go API изменяет остаток счёта в одной транзакции с созданием операции;
- OpenAPI задаёт контракт для клиентов;
- TypeScript-типы генерируются из OpenAPI;
- React показывает счета и операции и позволяет добавить покупку.

ИИ, чеки и обязательства намеренно не входят в первый срез.

## Быстрый старт

    make dev

После запуска:

- Web: http://localhost:5173
- API: http://localhost:8080
- PostgreSQL: localhost:55432

Остановка:

    make down

## Проверки

    make test

После изменения api/openapi.yaml обновите клиентские типы:

    make generate-api

## Структура

    web/                  React-клиент
    cmd/api/              точка входа Go API
    internal/accounts/    предметный модуль счетов
    internal/categories/  предметный модуль категорий
    internal/transactions предметный модуль операций
    internal/platform/    конфигурация, БД и HTTP-композиция
    api/openapi.yaml      стабильный контракт клиентов
    migrations/           PostgreSQL-миграции
    docs/                 архитектурные решения
