## Проблема и пользовательский результат

1. Суммы вводятся без разделителей: `20000000` в «Общая сумма» нечитаемо,
   легко ошибиться на порядок. Нужен ввод с группировкой разрядов
   (`20 000 000`) и запятой для копеек — как Grace показывает суммы.
2. В профиле «Профиль сохранён.» появляется отдельной ячейкой сетки под
   карточкой, далеко от кнопки. Обратной связи рядом с действием нет, и
   сохранение легко нажать повторно: каждое — `POST /api/auth/profile` +
   `GET /api/auth/me` (на скриншоте пять таких пар).
3. При пустом списке счетов кнопка «Добавить первый счёт» видна в шапке
   любой страницы, включая «Профиль и доступ».

## Scope

- Общий `MoneyInput` в `web/src/shared/ui`: текстовое поле
  `inputMode="decimal"`, отображение с неразрывными пробелами между
  разрядами и запятой, приём `.`/`,`, вставки с пробелами/NBSP, максимум
  2 знака после запятой; наружу — строка, которую разбирает существующий
  `parseMinor` (integer minor units). Без spinner-стрелок и `type="number"`.
- Заменить `type="number"` и голые `inputMode="decimal"` для денег:
  обязательство (общая сумма, платежи графика), счёт (остаток), операция,
  подписка, сведения о кредите (сумма выдачи), черновик графика, фото чека
  (итог), импорт (сумма — сейчас «в копейках»: показывать рубли).
  Количество в чеке (`quantity`) не деньги — остаётся числом, без spinner.
- Профиль: сообщение об успехе/ошибке — внутри своей карточки, рядом с
  кнопкой действия (`role="status"`/`role="alert"`), отдельно для «Личные
  данные» и «Почта и вход»; «Сохранить профиль» неактивна, пока данные не
  изменены; после успешного сохранения кэш `auth-session` обновляется
  ответом без повторного `GET /api/auth/me`.
- Кнопка «Добавить счёт» в шапке при пустом списке: только на `/`,
  `/accounts`, `/operations`, `/payments`.

## Предметная модель и инварианты

- Разбор строки → minor units только через `parseMinor` (BigInt, без float);
  `Math.round(value * 100)` из форм удаляется.
- Отображение и разбор взаимно обратны: `format(parse(s))` устойчиво.
- Значение вне `Number.MAX_SAFE_INTEGER` — ошибка поля, не обрезка.

## API и OpenAPI

сессии (`displayName`, `avatarUrl`) переносятся в кэш `auth-session` на клиенте.

## UI

`MoneyInput` выглядит как `Input`, цифры tabular, валюта — суффиксом в поле
(`₽` или код). Курсор не прыгает при вставке разделителей (позиция
пересчитывается по числу цифр слева от него).

## Ошибки и негативные сценарии

`1 234,5` → 123450; `1234.56` → 123456; `1,2,3` → ошибка; `-5` в сумме
обязательства → ошибка; вставка `20 000 000,00 ₽` → 2000000000; пусто →
«Укажите сумму»; 3 знака после запятой → ошибка; IME/автозаполнение;
быстрый двойной клик «Сохранить профиль» → один запрос.
