## Проблема и пользовательский результат

Платёж графика бывает только «просрочен» или «предстоит»: за день до списания
Обзор и «Платежи» выглядят так же, как за месяц. Считать «скоро» в React —
бизнес-правило в UI (AGENTS.md). Результат: за 3 дня до даты платёж получает
жёлтый статус «Через 3 дня», затем «Через 2 дня», «Завтра», «Сегодня» — те же
окна, что у email-напоминаний SPEC-0034.

## Scope

1. Go — единственный источник правила: `obligations.DueSoonDays = 3`
   (совпадает с окнами напоминаний 3/1 день), функция
   `obligations.DueIn(asOf, dueOn)` → число дней до даты по календарю
   Asia/Yekaterinburg.
2. Денежная позиция (`CashScheduledPayment`): `timing` получает значение
   `due_soon` (неоплаченный остаток, 0–3 дня до даты), плюс `daysUntilDue`
   (отрицательное — просрочен). Суммы «Просрочено / Предстоит» не меняются:
   `due_soon` входит в «Предстоит».
3. Графики обязательств (`ScheduledPayment`): `dueSoon` (bool) и
   `daysUntilDue`; `status` прежний.
4. UI: на Обзоре и в «Платежах» — `StatusBadge tone="warning"` с текстом по
   `daysUntilDue`: «Сегодня», «Завтра», «Через 2 дня», «Через 3 дня».
   «Частично оплачен» переходит на тон `info`, чтобы жёлтый означал только
   «скоро» (просроченный частично оплаченный остаётся `danger`).

## Non-goals

- Новые email/push-уведомления и изменение окон SPEC-0034 (они уже 3/1 день
  для подписок и кредитов с включёнными напоминаниями).
- Настраиваемый порог.

## Предметная модель и инварианты

- Дни считаются по датам (`due_on` — дата, «сегодня» — дата в
  Asia/Yekaterinburg), без времени суток.
- Оплаченные полностью платежи не бывают «скоро» и «просрочены».

## API и OpenAPI

- `CashPositionPayment.timing`: `overdue | due_soon | upcoming`; новое
  обязательное `daysUntilDue` (integer).
- `ScheduledPayment`: новые обязательные `dueSoon` (boolean), `daysUntilDue`
  (integer).

## Данные, миграция и rollback

Без миграции: значения вычисляются при чтении.

## Критерии приёмки

- [ ] AC1: платёж через 0–3 дня с неоплаченным остатком — `due_soon` и
  `dueSoon=true`; через 4 дня — `upcoming`; вчера — `overdue`; оплаченный —
  ни то ни другое; `daysUntilDue` верен.
- [ ] AC2: суммы «Просрочено / Предстоит / Всего» не изменились.
- [ ] AC3: Обзор и «Платежи» показывают жёлтый статус с «Сегодня / Завтра /
  Через N дня», «Частично оплачен» — не жёлтый.
