## Проблема и пользовательский результат

На «Категории» личные категории можно только переименовать
(`PATCH /api/v1/categories/{id}`), общие — только читать; удалить нельзя ничего.
У категорий нет иконок, поэтому список операций не может их показать (SPEC-0043).
Результат: человек переименовывает, меняет иконку, скрывает или удаляет
категорию, а операции не теряют категорию.

## Scope

1. Личная категория: переименовать, выбрать иконку, удалить.
2. Удаление категории с операциями: человек выбирает, в какую категорию
   перенести операции (покупка обязана иметь категорию —
   `CHECK kind <> 'purchase' OR category_id IS NOT NULL`); перенос и удаление
   — одна атомарная операция Go, с предпросмотром «перенесём N операций в …».
3. Общая категория: изменить нельзя, но можно скрыть у себя (не показывать
   в выборе для новых операций); старые операции остаются с ней.
4. Иконка категории: ключ из фиксированного набора Lucide (≈40 иконок:
   продукты, транспорт, дом, связь, здоровье, развлечения, одежда, дети,
   животные, подарки, кафе, путешествия, образование, подписки, кредит, …);
   у общих категорий — иконка по умолчанию из сида.

## Non-goals

- Подкатегории и бюджеты по категориям.
- Слияние категорий без удаления (покрывается удалением с переносом).

## Текущее поведение и доказательства

- `migrations/000001…`: `category_id … ON DELETE RESTRICT`; покупка требует категорию.
- `web/src/pages/home/ui/Categories.tsx`: «Переименовать» только для личных.
- В таблице `categories` нет поля иконки.

## Предметная модель и инварианты

- `categories.icon TEXT NULL CHECK (icon IN (…набор…))`.
- `category_hidden{owner_id, category_id}` для скрытия общих.
- Удаление с переносом: целевая категория того же вида и доступна владельцу;
  число перенесённых операций = числу в предпросмотре, иначе отказ.

## API и OpenAPI

- `PATCH /api/v1/categories/{id}` — `name`, `icon`.
- `POST /api/v1/categories/{id}/delete-preview` → `{operations, receipts}`.
- `DELETE /api/v1/categories/{id}?moveTo={id}` (Idempotency-Key).
- `PUT/DELETE /api/v1/categories/{id}/hidden`.
- `Category`: `icon`, `hidden`, `operationCount`.

## Данные, миграция и rollback

Колонка `icon` с сидом иконок общих категорий, таблица скрытия.
DOWN удаляет колонку и таблицу (данные иконок теряются — допустимо).

## UI

Карточка категории: иконка, название, число операций; «Изменить»
(название + сетка иконок), «Скрыть» для общих, «Удалить» — диалог с выбором
категории для переноса и итогом «N операций будут перенесены».

## Ошибки и негативные сценарии

Удаление без выбора переноса при наличии операций; перенос в категорию
другого вида; дубль имени; конкурентное удаление; скрытие категории,
выбранной в открытой форме.

## Критерии приёмки

- [ ] AC1: личная категория переименовывается, меняет иконку, удаляется с переносом.
- [ ] AC2: операции после удаления в выбранной категории, итоги статистики не изменились.
- [ ] AC3: общая категория скрывается из выбора, старые операции не меняются.
- [ ] AC4: иконки категорий доступны в API и показаны на «Категории».
