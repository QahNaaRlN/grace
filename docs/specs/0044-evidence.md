Проверки: `make test-integration` (все пакеты, exit 0); `make test` — Go `ok`, web 195 тестов,
lint, build; `git diff --check` — чисто.

Решения и отклонения:
- Решение 1: предпросмотр по фильтру — до 1 000 строк; разбиение на части — сужением фильтра.
- Курсор строк и истории — непрозрачный номер позиции (раньше — UUID): сортировка по дате и
  сумме несовместима с курсором по id. Старые клиенты передают курсор из ответа как есть.
- «С вопросами» теперь считается по сохранённому полю, а не перебором кандидатов отчёта на
  каждую строку; смысл фильтра прежний (замечания источника или кандидаты совпадения).
- `scripts/test-imports.sh` не менялся: новый тест входит в `./internal/imports`.
