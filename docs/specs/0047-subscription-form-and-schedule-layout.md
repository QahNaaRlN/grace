## Проблема и пользовательский результат

1. Валюта подписки, обязательства и строки импорта вводится текстом: можно опечататься
   («RUR», «руб»), и форма отклонит сохранение.
2. У подписки нет категории, поэтому её нельзя отнести к расходам так же, как покупку.
3. «Первый или последний платёж отличается»: поля сдвинуты относительно формы, рамка фокуса
   обрезана.
4. Таблица графика смещена на одну ячейку: суммы стоят под «Дата», даты — справа и на строку
   ниже, у последней суммы нет даты.

Результат: валюта выбирается из списка (RUB по умолчанию); у подписки обязательная
категория расхода; блок сумм первого/последнего платежа и таблица графика выровнены.

## Scope

1. Общий `CurrencySelect` (`shared/ui`) и список `currencies` (`shared/lib`): RUB по
   умолчанию, USD, EUR, CNY, KZT, BYN, TRY, AED, GBP; уже сохранённая валюта вне списка
   показывается отдельной опцией, чтобы правка не меняла её молча. Используется в формах
   подписки, обязательства и решения по строке импорта.
2. Подписка: `categoryId` — категория расхода (`kind = expense`), обязательна при создании и
   изменении, как у покупки; в выборе нет скрытых категорий (кроме текущей). Карточка
   подписки показывает иконку и название категории. Существующие подписки без категории
   остаются валидными, при следующем сохранении категорию нужно выбрать.
3. Удаление категории (SPEC-0042): подписки переносятся в выбранную категорию вместе с
   операциями; если операций нет и категорию удаляют без переноса, у подписок категория
   сбрасывается (БД: `ON DELETE SET NULL`).
4. ScheduleBuilder: ячейка заголовка «Действия» занимает место в сетке; блок
   «Первый или последний платёж отличается» — в выделенной области с теми же отступами,
   рамка фокуса не обрезается (`Disclosure` получает внутренний отступ).

## Non-goals

- Курсы валют и пересчёт; новые валюты счетов (счёт по-прежнему RUB).
- Автоматическое создание покупок по подписке.

## API и данные

- Миграция 23: `subscriptions.category_id uuid REFERENCES categories(id) ON DELETE SET NULL`,
  индекс по `category_id`.
- OpenAPI `Subscription`: `categoryId` (`uuid | null`), в запросе сохранения обязателен.
