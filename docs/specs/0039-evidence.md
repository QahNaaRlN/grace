Ветка: `codex/obligation-schedule` от `main` (`82f9095`), implementation commit `e677593`.
Статус: `integrated` — PR #37, merge `090ebad`; CI `main` пройден. Production развёрнут 2026-10-14 (release `8ad9705`, workflow run 38560119989).

| Критерий | Реализация | Исполняемое свидетельство |
|---|---|---|
| AC1 | `features/obligation-schedule`: `groupSchedule` + `ObligationSchedule`; сводка «Оплачено N из M платежей · следующий …», «Просрочено N»; группы «Требуют внимания», «Ближайшие», «Дальше», «Оплачено» | `ObligationSchedule.test.tsx` «shows what needs action…»: ипотека 240 платежей → 2 + 3 строки, «Ещё 216 платежей до 15.12.2044», «Оплачено 19 платежей», 5 строк в DOM. Предпросмотр `docs/ui-review` (рассрочка 240 платежей): 5 строк до раскрытия |
| AC2 | `Folded`: кнопка с `aria-expanded`/`aria-controls`, скрытые строки не монтируются; ≥ 50 строк — второе «Свернуть» внизу | Тест «opens exactly the announced rows…»: +216 и +19 строк, Enter и пробел, фокус остаётся на переключателе |
| AC3 | Просроченный/частично оплаченный/неизвестный статус — в «Требуют внимания», `StatusBadge` словом и иконкой; > 5 — «Ещё N требуют внимания» | Тест «never hides an unknown status…»: 5 видимых, «Ещё 4», после раскрытия — «Статус неизвестен» |
| AC4 | «Связать платёж» в строке, один выбор открыт за раз; тот же `POST …/settlements` с `Idempotency-Key`; после связи фокус — на сводке | Тест «links a payment from the folded part…»: платёж 15.12.2044 из раскрытой группы, путь, `paymentId: p240`, `financialEventId`, ключ, фокус |
| AC5 | Подсказка «Сначала создайте подходящий платёж по обязательству.» — одна на обязательство | Тот же тест: ровно одна подсказка без кандидатов, нет кнопок «Связать платёж» |
| AC6 | ≤ 6 платежей — список целиком; `completed` — «Оплачено N» свёрнуто | Тест «shows a short schedule whole and folds a completed one» |
| AC7 | `groupSchedule` читает только `status`, `isOverdue`, `remainingMinor`, `position` | `group-schedule.test.ts`: каждый платёж ровно в одной группе и по `position` — все оплачены, все будущие, partially_paid+overdue, неизвестный статус, 1 и 600 строк; суммы не меняются |
| AC8 | Строка переносится на узком экране; бейдж статуса переносится внутри строки | Предпросмотр `docs/ui-review` (рассрочка 240 платежей): 320, 390 и 1280 px — `scrollWidth = clientWidth`, ни один бейдж/кнопка не выходит за строку, нет кнопок ниже 44 px; 1280 px проверено и в тёмной теме. Скриншоты 320 px просмотрены вручную, в репозиторий не сохранены |

Проверки: `make test` — Go `ok`, web 211 тестов, lint, build; `git diff --check` — чисто.
Go, OpenAPI и данные не менялись — интеграционные тесты не затронуты (их прогоняет CI).

Отклонения:
- В fixture `docs/ui-review` график на 240 платежей — «Рассрочка», а не кредит: мок предпросмотра
  не отдаёт сведения кредита, и `LoanPanel` в нём падает (не связано с этой спецификацией).
- Статусы и тоны платежа перенесены из `HomePage.tsx` в компонент графика без изменений
  (жёлтый — только «скоро», SPEC-0046).
