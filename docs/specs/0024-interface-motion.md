## Проблема и пользовательский результат

Во вкладке браузера виден прежний знак инструмента сборки. Меню и общие
интерактивные элементы должны ощущаться частью единого интерфейса Grace:
небольшие движения и затухания помогают понять открытие/закрытие и нажатие.

## Scope и UI

- SVG favicon в существующем стиле: сердце с пульсом, белый контур, индиго
  #4338ca, скруглённый фон. Новый URL/version в HTML обновляет прежний favicon.
- Единые CSS duration/easing: открытие около 200 ms, закрытие около 140 ms;
  движение окна не более 8 px, масштаб не менее 0.97. Overlay — opacity.
- Общие Radix dialog/menu и select; item-aligned select использует только
  opacity, сохраняя привязку к выбранному элементу.
- Короткие переходы цвета/focus для навигации, кнопок и полей; лёгкий отклик
  на активное нажатие доступной кнопки. Первое появление main — мягкий fade.
- prefers-reduced-motion полностью отключает декоративные анимации и
  переходы, включая tw-animate-css; focus и видимые состояния сохраняются.

## Non-goals

Изменения финансовой логики, сумм, API/БД, layout, новые анимационные
зависимости, анимация чисел, постоянное движение карточек и deploy.
Не вводить route keys/remount, способные сбросить заполненные формы.

## Текущее поведение

Main 2c21983: favicon.svg содержит постороннюю фиолетовую иконку;
AppLayout использует HeartPulse и индиго. Общие Radix dialog/select имеют
утилиты tw-animate-css с duration-100, но общего reduced-motion правила нет.
Кнопки и некоторые поля имеют переходы, навигация/строки — мгновенный hover.
Основание: SPEC-0020, docs/vision.md, docs/architecture.md.

## Предметная модель и инварианты

CSS меняет только представление. Фокус, Esc, click, disabled, focus trap и
возврат фокуса управляются существующим Radix. Анимации не добавляют timers,
event handlers или задержек отправки. Денежные тексты не интерполируются.
Окно остаётся по центру, списки не смещают layout; touch targets ≥44px.
Значения duration и easing общие. Reduced motion доступен без настройки Grace.

## API и OpenAPI

## Ошибки и негативные сценарии

Проверить повторное открытие, быстрое закрытие, Esc/focus, светлую/тёмную темы,
mobile и reduced-motion. Не применять анимации трансформации к item-aligned
select. Disabled-кнопки не реагируют масштабом. Без CSS функциональность
сохраняется; SVG не содержит скриптов, внешних ссылок или шрифтов.
