# Decision 0001: spec-first и единый каталог worktree

- Статус: accepted
- Дата: 2026-10-04
- Владелец решения: owner

## Решение

Grace разрабатывается по spec-first процессу. Изменения production-кода
начинаются только после явного принятия спецификации владельцем.

Основная рабочая копия:

    /home/krmiftakhov/PersonalProjects/grace

Каталог всех дополнительных рабочих деревьев:

    /home/krmiftakhov/PersonalProjects/grace-worktrees

Основная копия предназначена для просмотра, интеграции и post-merge проверок.
Работа над отдельным изменением выполняется в
`grace-worktrees/<work-item>` на отдельной ветке `codex/<slug>`.

## Причины

- спецификация и реализация не смешиваются;
- незавершённая работа не загрязняет интеграционную копию;
- несколько независимых изменений не меняют состояние друг друга;
- точная ветка, каталог и доказательства проверки остаются воспроизводимыми.

## Следствия

- draft-спецификация не разрешает реализацию;
- принятая спецификация не означает, что реализация завершена или интегрирована;
- dirty worktree нельзя удалять автоматически;
- после интеграции чистый worktree удаляется через `git worktree remove`, затем
  выполняются `git worktree prune` и `git worktree list`;
- `--force` и ручное удаление каталогов worktree запрещены.
