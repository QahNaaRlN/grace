# Grace: визуальное направление, 2026-10-09

Проработка по accepted [SPEC-0029](specs/0029-design-foundations.md).
Сравнение: [локальный интерактивный прототип](design-preview.html).
Владелец выбрал петрольную палитру 2026-10-09. Tokens применены локально.
Production пока не обновлён. Марка — прозрачная монета со знаком ₽ и пульсом справа: деньги и здоровье в одном знаке.

У всех есть отдельная dark palette, а не инверсия light. Цвет действия не
заменяет смысл статуса: подтверждение/ошибка/неизвестное имеют текст.
Главная сумма и источники сохраняют валюту, точность и границы покрытия.

## Единые правила

Spacing scale 4/8/12/16/24/32: label → control8, controls16, card padding24
(20 в компактном примере), между sections24, перед actions24, между actions12.
Radius controls12, cards16; большие суммы с tabular nums. Body16/24,
secondary14/21, section20/26, сумма32–44. Не добавлять индивидуальные радиусы,
градиенты и декоративные акценты каждой новой функции.

Главное действие44–48px; на одном шаге одна primary button. Clickable — pointer,
текстовый ввод — text, недоступное native control — not-allowed. Видимый focus
для клавиатуры; label постоянный, placeholder не заменяет label. Reduced motion
сохраняет состояния и отключает движение. Status не передаётся одним цветом.
Body/muted/action text contrast ≥4.5:1 по [WCAG contrast](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html).

## Receipt: следующий дизайн-scope

Фото → проверить данные → подтвердить. На втором шаге сначала магазин/дата/
сумма/счёт и компактные позиции. Бренд/упаковка — по раскрытию. Неизвестное
время обозначено; AI value отделено от owner correction. Поиск совпадений
должен предшествовать выбору create/link, без фиктивного создания расхода.
До confirmation явно виден эффект на баланс. Consent на передачу фото
остаётся отдельным действием перед inference. Прототип показывает только
review composition; полный consent/upload/storage flow в нём не реализован.

## Analysis: следующий дизайн-scope

Сначала Go summary/coverage, затем интерпретации со ссылками и деталями.
Ошибка модели не прячет core facts. Paid retry — отдельное действие.
Технические routing confidence не заменяют понятное объяснение неопределённости.
Privacy/модель/стоимость доступны человеку, но не доминируют над результатом.
